# Fresh-start reporting determination — provisional

The confirmation order is dated September 2, 2026; the plan becomes effective September 30. Both ASC 852 conditions must hold upon emergence. The ASC test calls for the reorganization value of assets and post-petition liabilities plus allowed claims **immediately before confirmation**, and for the percentage of the emerging entity's **voting shares** received by old voting shareholders. [FASB ASC 852-10-45-19 through 45-29](../../library/asc852_fresh_start.md)

| Condition | Supplied figures and calculation | Result on stated assumptions |
|---|---|---|
| Value test | $14,000,000 stated reorganization/enterprise value < $16,200,000 stated post-petition liabilities and allowed claims; difference **$2,200,000**. | **Passes**, if these effective-date figures also represent the ASC asset value and liabilities immediately before September 2 confirmation. |
| Voting-share test | Existing equity retains **60% of reorganized equity**, which is 10 percentage points above the less-than-50% threshold. | **Fails**, if the retained 60% consists of voting shares received by the pre-confirmation voting shareholders. |

**Conclusion on those assumptions: no fresh-start reporting**, because the second condition fails even though the first passes. The plan says “equity,” not “voting shares,” and labels the $14 million as an effective-date enterprise value rather than a pre-confirmation asset value. The actual voting rights and values at the required test date were not supplied, so the conclusion cannot be finalized from the available record. If old holders receive less than 50% of voting shares and the value test still passes using the required measures, fresh-start reporting would apply; reassess before issuing the emergence statements.
